# Zusaetzliche Caddy-Sites

`install.sh` legt hier optionale Site-Bloecke ab (z.B. `office.caddy` fuer die eigene
ONLYOFFICE-Subdomain, Security-Audit R-24). Die Hauptkonfiguration importiert `*.caddy` aus
diesem Verzeichnis; ohne passende Datei passiert nichts. Erzeugte `*.caddy`-Dateien sind nicht
versioniert.
